# JANART STUDIO - Галерея искусств

## Описание
Веб-сайт галереи искусств JANART STUDIO с админ-панелью для управления работами.

## Функциональность
- Просмотр галереи работ
- Модальные окна для детального просмотра
- Админ-панель для управления контентом
- Адаптивный дизайн
- Загрузка изображений

## Структура файлов
```
janart-studio/
├── index.php              # Главная страница
├── admin-panel.php        # Админ-панель
├── gallery-data.json      # Данные галереи (JSON)
├── images/               # Папка с изображениями
│   ├── gallery/          # Изображения галереи
│   └── freepik-export-*.jpeg
├── .htaccess            # Конфигурация Apache
└── README.md            # Документация
```

## Установка на reg.ru

### 1. Создание поддомена
1. Зайдите в панель управления reg.ru
2. Создайте поддомен `janart-studio.ru`
3. Направьте его на папку `janart-studio/`

### 2. Загрузка файлов
1. Загрузите все файлы в папку `janart-studio/` на хостинге
2. Убедитесь, что права доступа к папке `images/` установлены в 755
3. Убедитесь, что файл `gallery-data.json` доступен для записи (644)

### 3. Настройка базы данных (опционально)
Если нужна база данных для более сложной функциональности:
1. Создайте базу данных в панели управления
2. Импортируйте структуру таблиц
3. Обновите код для работы с БД

## Использование

### Просмотр галереи
- Откройте `https://janart-studio.ru`
- Просматривайте работы в галерее
- Кликайте на работы для детального просмотра

### Админ-панель
- Перейдите по адресу `https://janart-studio.ru?admin=12345`
- Добавляйте новые работы
- Редактируйте существующие работы
- Удаляйте работы

## Разработка

### Локальная разработка
1. Установите локальный сервер (XAMPP, OpenServer)
2. Скопируйте файлы в папку сервера
3. Откройте `http://localhost/janart-studio/`

### Смарт-оплата (Сам.Эквайринг)
1. Подставьте реальные `SELFWORK_MERCHANT_ID` и `SELFWORK_SECRET_KEY` в `lib/payment-config.php` (или через переменные окружения `SELFWORK_MERCHANT_ID` / `SELFWORK_SECRET_KEY`).
2. Проверьте, что `SELFWORK_STORE_DOMAIN` соответствует адресу сайта.
3. После подтверждения заказа фронт отправляет запрос на `api/smart-payment-init.php`, который формирует подпись и проксирует POST к `https://pro.selfwork.ru/merchant/v1/init`.
4. Настройте callback-URL и настройки уведомлений для вашего магазина в личном кабинете Сам.Эквайринг и добавьте требуемый `<meta>`-тег для подтверждения домена (уже есть в `index.html`).
5. Логи запросов и ошибок можно посмотреть в `storage/smart-payment.log`.
